# Privacy Policy for Florence Extension

Effective date: July 9, 2026

Florence Extension is a Chrome extension that adds a workflow automation sidebar to Research Binders at `https://us.v2.researchbinders.com/`.

## Information the extension processes

Florence Extension may process information visible to an authorized user inside Research Binders, including:

- Study, site, protocol, document log, and training log information.
- Names, roles, responsibilities, and other team-member workflow information shown in Research Binders.
- User-entered workflow data, such as Study Library entries imported or typed by the user.
- Extension settings, including keybinds, button layout, sidebar visibility, selected tabs, and workflow state.

Florence Extension does not collect usernames or passwords.

## How information is used

The extension uses Research Binders page content only to provide user-triggered workflow automation. This includes scanning visible tables or lists, preparing local workflow output, filling form fields, clicking page controls, copying generated text after user action, and restoring user settings across browser sessions.

## Local storage

Florence Extension stores settings and user-entered workflow data locally in the browser using `chrome.storage.local` and, for some settings, the Research Binders page origin's local storage. This local storage is used to remember extension preferences and workflow state across page reloads and browser sessions.

## Data sharing

Florence Extension does not sell user data, does not use user data for advertising, and does not transfer extension data to third-party services.

The extension may interact with Research Binders pages using the user's existing authenticated browser session. Any information submitted into Research Binders through user-triggered automation is handled by Research Binders according to the user's existing relationship with that service.

## Remote code

Florence Extension does not execute remotely hosted code. All extension code is included in the installed extension package.

## Clipboard use

Some features copy generated workflow text to the clipboard after user action. Florence Extension does not read clipboard contents and does not transmit clipboard contents to third parties.

## File import and export

Study Library features may import or export spreadsheet files selected or generated by the user. Imported files are processed locally in the browser and stored locally only when the user chooses to import the data.

## Data retention and deletion

Data stored by Florence Extension remains in the user's browser until the user clears it, resets the relevant feature, or uninstalls the extension. Users can remove locally stored extension data through Chrome's extension/site data controls or by uninstalling the extension.

## Security

Florence Extension limits its host access to `https://us.v2.researchbinders.com/*` and requests only the permissions needed for its Research Binders workflow automation features.

## Changes to this policy

This privacy policy may be updated when Florence Extension changes how it processes data. Updates should include a new effective date.

## Contact

For privacy questions, contact the extension publisher using the support contact listed on the Chrome Web Store listing or developer account.
