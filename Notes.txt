Single purpose
Florence Extension adds a sidebar to Research Binders that helps authorized users automate repetitive study, document log, training log, and team-member workflow tasks inside https://us.v2.researchbinders.com/.

Short description
Extension sidebar for Research Binders.

Detailed description
Florence Extension runs only on https://us.v2.researchbinders.com/ and adds a right-side sidebar with workflow buttons for common Research Binders tasks. It helps authorized Research Binders users scan page content, collect visible study or log information, fill repetitive form fields, copy generated text, and store user-configured settings such as keybinds, button layout, and study library entries.

Permission justification: storage
The storage permission is used to save extension settings and user-entered workflow data locally in chrome.storage.local. This includes the active Training Log tab, whether Training Log scanning is active, the latest generated Training Log state, and Study Library entries entered or imported by the user. The data is used only to restore the user's extension state across page reloads and browser sessions. It is not sold, shared, or transmitted to any third-party service by the extension.

Host permission justification: https://us.v2.researchbinders.com/*
The extension must run on Research Binders pages to add the Florence Extension sidebar and interact with page content selected by the authenticated user. It reads same-origin page content, scans tables/lists, and fills or clicks Research Binders controls as part of user-triggered workflow automation. The host permission is limited to https://us.v2.researchbinders.com/* because the extension is only useful on that site.

Content script justification
The content script injects the sidebar UI and performs user-triggered automation directly in the Research Binders page. It does not run on unrelated websites.

Remote code declaration
No. The extension does not execute remotely hosted code. All extension code is packaged in the submitted extension ZIP. The script may fetch same-origin Research Binders HTML pages using the user's existing authenticated session, but fetched HTML is parsed as page content and is not executed as extension code.

Data collection disclosure
The extension reads Research Binders page content that the authenticated user can already access, including visible names, roles, study metadata, document-log entries, and training-log information needed for the selected automation task. The extension also stores local configuration and user-entered Study Library / Training Log data in browser storage.

Data sharing disclosure
The extension does not sell user data, does not use user data for advertising, and does not transfer user data to third parties. Data is processed locally in the browser and, where applicable, used only to interact with the Research Binders website that the user is already using.

Personally identifiable information
Research Binders pages may contain names, roles, site information, or study-related records. The extension processes this information locally only to complete user-triggered automation tasks.

Authentication information
The extension does not collect usernames or passwords. It uses the user's existing Research Binders authenticated browser session when reading same-origin Research Binders pages.

Clipboard disclosure
Some features copy generated workflow text to the clipboard after user action. Clipboard contents are not read by the extension and are not transmitted to third parties.

File import/export disclosure
Study Library features may import or export spreadsheet files selected or generated by the user. Imported spreadsheet data is processed locally and stored in chrome.storage.local if the user chooses to import it.

Privacy policy summary
Florence Extension processes Research Binders page content locally to provide workflow automation. It stores user settings and user-entered workflow data locally in the browser. It does not transmit extension data to third-party services, sell data, or use data for advertising.

Limited use certification
User data is used only to provide and improve the extension's single purpose: Research Binders workflow automation for authorized users. Data is not used for advertising, creditworthiness, resale, or unrelated purposes.

Test instructions for reviewers
1. Install the extension from the submitted ZIP.
2. Sign in to a test account at https://us.v2.researchbinders.com/.
3. Navigate to a Research Binders page containing document log, training log, study, or team-member workflow data.
4. Press F2 to show or hide the Florence Extension sidebar.
5. Use the gear icon to confirm settings can be changed and saved.
6. Click a workflow button appropriate for the test page and confirm the extension scans visible Research Binders content or prepares the expected local workflow output.
7. Confirm the extension does not appear or run on unrelated websites.

Reviewer account note
Because the extension only works on an authenticated Research Binders environment, provide Google reviewers with a temporary test account, test URL, and any sample study/log data needed to verify the listed features.


Suggested visibility
Use Private or Unlisted first if this extension is only for an internal or limited Research Binders team. Use Public only if it is intended for all Research Binders users and the listing clearly states that a Research Binders account is required.
